# SkillBridge

## Smart Learning & Placement Management Portal

SkillBridge is a Python-based learning and placement management portal designed to manage students, trainers, courses, and placement opportunities in one system.

## Features

### Student Module
- View available courses
- Enroll in courses
- View placement opportunities

### Trainer Module
- Trainer login
- Manage trainer-related activities
- View trainer information

### Admin Module
- Admin login
- Manage users
- Manage courses
- Manage placement information

### Authentication
- User login
- Role-based access
- Registration and logout

### Analytics
- View project and management-related analytics
- Generate reports

## Tech Stack

- Python
- JSON
- Git
- GitHub
- Jupyter Notebook
